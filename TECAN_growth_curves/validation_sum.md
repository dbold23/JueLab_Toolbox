# Synthetic validation summary — moved

This file used to hold a hand-kept copy of the synthetic validation summary. It
was dated 2026-02-12, reported an accuracy no run in this repository ever
produced, was referenced by nothing and was regenerated by nothing. It has been
replaced by this pointer so the repository states one set of benchmark numbers.

The current summary is **generated** from the benchmark's own `report.json`, on
demand. It is a build artefact, so no copy of it is committed and no file here
can go stale against the run:

- `synthetic_data/benchmark/v2/` — the tracked copy of the published first-peak
  run (`report.json`, `per_curve.csv`, `per_scenario.csv`,
  `gate_attribution.csv`, `HEADLINE.json`). Every current number lives here.
- `docs/BENCHMARK_LEDGER.md` — how the current numbers differ from the ones the
  repository published before the suite rebuild, and why.
- `synthetic_data/benchmark/v1/VALIDATION_SUMMARY.md` — the one committed
  `VALIDATION_SUMMARY.md`: the frozen pre-rebuild baseline, labelled as history.
  Numbers in that directory describe the v1 data and are not current.

Render the summary with:

```bash
make step-9              # re-runs the pipeline over the synthetic suite
make validation-summary  # renders <run-dir>/VALIDATION_SUMMARY.md from its report.json

# without a run directory, the published snapshot renders to stdout:
python synthetic_data/scripts/validation_summary.py --run-dir synthetic_data/benchmark/v2 \
    --output /tmp/VALIDATION_SUMMARY.md
```
