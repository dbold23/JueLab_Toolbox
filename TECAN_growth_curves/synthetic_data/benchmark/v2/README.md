# Benchmark snapshot v2 (current)

The tracked copy of the **published first-peak benchmark run**. The run itself
is written to
`synthetic_data/output/comprehensive_test/validation/first_peak/`, which
`.gitignore` excludes because it also holds a per-curve PNG for every curve
(211 MB). These are the small files out of that directory, copied here so the
published numbers are tracked, survive `make clean`, and can be quoted and
diffed without re-running anything.

Regenerate the run (and then refresh this directory) with:

```bash
MPLBACKEND=Agg python scripts/run_full_pipeline.py --steps 9 --no-adaptive
cp synthetic_data/output/comprehensive_test/validation/first_peak/{processing_results.csv,run_settings.json,report.json,per_curve.csv,per_scenario.csv,per_scenario_recovery.csv,gate_attribution.csv,classification_summary.png} \
   synthetic_data/benchmark/v2/
```

The dataset those files score is tracked at its own canonical location and is
not copied here: `synthetic_data/output/comprehensive_test/test_data/` plus
`MANIFEST.json` and `generation_summary.json` beside it.

Not copied: `plots/` (211 MB), `gate_attribution_all.csv`, and the four
`validation_*.png` comparison figures — all regenerated by the command above.
